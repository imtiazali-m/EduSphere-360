# EduSphere 360 — Accountant Manual
Accountant menu: Dashboard, Fee Invoices, Work Management.
- **Invoices:** create per student with category, amount, discount, due date; invoice number is generated if left blank.
- **Collection:** "Record payment" — amount (cannot exceed balance), method (cash, bank transfer, card, online, cheque, other), date (cannot be in the future), reference. A receipt number is returned.
- **Balances:** shown from the database balance snapshot; never negative.
- **History:** per-invoice payment history.
- **Fines:** enter a **Fine / late fee** on the invoice; it is included in the balance.
- **Reports:** the **Reports** page shows total invoiced, received and outstanding, and exports outstanding invoices to CSV. Printable receipts are not verified.
