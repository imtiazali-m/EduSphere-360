# EduSphere 360 — Teacher Manual
Teacher menu: Dashboard, Student Records, Attendance Register, Examinations, Exam Results, Assignments, Assignment Submissions, Timetable, Announcements, Work Management.
- **Attendance:** record Present / Absent / Late / Excused for a student and date.
- **Assignments:** create with class, subject, instructions, deadline, maximum marks; set Open/Closed.
- **Submissions:** review student work, award marks, write feedback, mark Graded or Returned.
- **Examinations & results:** view exams; enter marks (Draft); results become visible to students and parents only when set to Published.
Teachers have no owner-level administration or finance access. Per-class restriction of teacher access depends on the database policies (not verified live).
