# EduSphere 360 — Examination Officer Manual
Menu: Dashboard, Examinations, Exam Results, Announcements, Work Management.
- **Setup/scheduling:** title, type (midterm, final, quiz, monthly, practical, other), session, term, class, subject, date, start time, duration, room, invigilator, total marks, instructions.
- **Marks:** enter marks per student per exam (one result per student per exam).
- **Publication:** set result status Published to release to students and parents; Draft stays hidden.
The **Reports** page shows published vs draft results, average of published results and grade counts, with CSV export. No finance access. Separate assessment/grading-scheme management is not implemented beyond the grade column.
