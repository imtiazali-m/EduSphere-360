EduSphere 360 — Restore the complete Windows project

WHY THIS BUNDLE
Your current folder reported Test-Path .\package.json = False. That means the project root you are using does not contain the main package.json. This bundle restores the complete source tree, not just package.json.

IMPORTANT
- Do NOT delete your existing folder.
- Do NOT rerun the Supabase database migration.
- Your Supabase cloud project and saved records are separate from this local folder and are not changed by this restore.
- Do not share .env.local or any credentials.

RESTORE
1. Extract the ZIP to Downloads. After extraction, locate:
   Downloads\EduSphere360_DevKit\package.json
2. Open that exact EduSphere360_DevKit folder in VS Code using File > Open Folder.
3. If your old project has a .env.local file, copy it into the restored folder beside package.json. Do not copy .env.bootstrap or any secret file.
4. If you do not have .env.local, copy .env.example to .env.local and fill in your own Supabase Project URL and Publishable key.
5. Open Terminal > New Terminal and check:
   Test-Path .\package.json
   It must return True.
6. Install packages:
   npm.cmd install
7. Start the website:
   npm.cmd run dev -- --port 5174
8. Open the exact Local URL shown by Vite, normally http://localhost:5174.

CLOUD ADMIN
The no-secret registration patch is included. Public first-admin sign-up is disabled. Your existing manually created Supabase owner account is used for Online > Login > Administrator.

SECURITY
- Keep .env.local private. It should contain only the project URL and Supabase publishable key.
- Never place a Supabase secret/service_role key in browser files.
- Row Level Security remains enabled.
- This restore does not alter the hosted Supabase database, policies, Auth users, Edge Functions or stored records.
