EduSphere 360 — Faculty Attendance integration patch

IMPORTANT: This is an additive integration patch designed to preserve the Student Attendance page you just installed.
It deliberately does NOT replace src/components/RecordModule.tsx or any student attendance CSS.

Included:
- Dashboard navigation for Faculty Attendance
- Faculty Attendance module configuration
- Local/offline + Supabase table allow-list
- Separate Supabase migration 004_faculty_attendance.sql

Install:
1. Stop Vite with Ctrl+C.
2. Extract this ZIP into the EduSphere360_DevKit project root and choose Replace for the included files only.
3. Confirm supabase/migrations/004_faculty_attendance.sql exists. Keep all earlier migrations, including your Guardian migration.
4. Run: npm.cmd run build
5. If using Supabase Cloud, run the SQL in 004_faculty_attendance.sql in Supabase SQL Editor after earlier migrations have been applied.
6. Start: npm.cmd run dev
7. Open the Faculty Attendance page. Create faculty profiles first; attendance uses the Employee ID from Faculty & Staff.

Statuses: Present, Absent, Late, Half day, Leave. Fields: Employee ID, faculty name, department, date, check-in, check-out, notes.
